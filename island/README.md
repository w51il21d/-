# 아일랜드 (갤럭시 S24+용 다이나믹 아일랜드)

화면 위 카메라 구멍 둘레에 검은 알약 모양 창을 띄워 다음을 보여줍니다.

| 기능 | 작게 | 누르면 (펼침) |
|---|---|---|
| 음악 | 앨범 사진 + 움직이는 막대 | 제목·가수, 재생 위치 막대, 이전·재생·다음 |
| 통화 | 전화 아이콘 + 통화 시간 | 상대 이름, 앱이 주는 버튼(스피커·끊기 등) |
| 타이머·스톱워치·알람 | 남은 시간 | 버튼(일시정지·취소 등) |
| 길 안내 (T map, 카카오내비, 네이버·구글 지도 등) | 다음 안내까지 거리 | 안내 문구, 안내 종료 |
| 새 알림 | 앱 이름, 보낸 사람, 내용 한 줄 (4초) | 전체 내용 + 버튼(읽음·좋아요 등) |
| 충전 | 번개 + 배터리 % | 완전 충전까지 남은 시간 |
| 배터리 부족 (20·10·5%) | 빨간 배터리 + % | 안내 문구 |
| 소리·진동·무음 전환 | 아이콘 + 모드 이름 | |
| 블루투스 이어폰 연결 | 이어폰 + 배터리 % | |

조작: **짧게 누르면 펼침**, 펼친 상태에서 다시 누르면 그 앱이 열림, **길게 누르면 바로 앱 열기**, 위로 쓸면 닫기. 펼친 뒤 7초 동안 손대지 않으면 자동으로 접힙니다.
동영상·게임처럼 상태바가 사라지는 화면에서는 저절로 숨습니다.

## 설치

1. 폰 브라우저로 이 주소를 엽니다 → APK가 내려받아집니다.
   `https://github.com/w51il21d/-/raw/island-apk/Island.apk`
   (저장소가 비공개라면 GitHub에 로그인한 상태여야 합니다.)
2. 내려받은 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 경고가 나오면 허용합니다.
3. **아일랜드** 앱을 열고 [권한] 칸의 버튼을 차례로 누릅니다.
   - 접근성 → 설치된 앱 → 아일랜드 표시 → 켜기
   - 알림 접근 → 아일랜드 → 허용
   - 근처 기기 → 허용 (이어폰 이름 표시용, 선택)
4. 접근성이나 알림 접근의 스위치가 회색이라 눌리지 않으면:
   앱 화면의 [앱 정보 열기] → 오른쪽 위 ⋮ → **제한된 설정 허용** → 3번을 다시 합니다.
5. 앱의 [미리보기] 버튼(알림·충전·타이머)으로 모양을 확인하고, [위치와 크기]에서 카메라에 맞게 조정합니다.

## 함께 맞추면 좋은 설정

- **삼성 알림 팝업 끄기**: 새 알림이 아일랜드와 삼성 팝업에 겹쳐 두 번 뜹니다.
  설정 → 알림 → 알림 팝업 스타일 → "간략히" 또는 앱별로 팝업 끄기.
- O.status와 함께 써도 서로 다른 자리(가운데 / 좌우)라 겹치지 않습니다.
